# Provenance

The fixture contains the byte-exact input and expected syntax result of each
entry in the [W3C RDF 1.1 N-Quads manifest](https://github.com/w3c/rdf-tests/blob/b8c483557a64544247422cb979d693b52d23e305/rdf/rdf11/rdf-n-quads/manifest.ttl)
at revision `b8c483557a64544247422cb979d693b52d23e305`. The entries are embedded as base64 to preserve
newlines, controls and escape sequences across platforms. The fixture records
the original path and SHA-256 of every input.
