# Provenance

The named colours of [CSS Color Module Level 4](https://www.w3.org/TR/css-color-4/#named-colors), section 6.1, with
their sRGB values as lowercase hex. The specification defines the 148 names (including the `grey` spellings) and their
values; the file lists them in the specification's alphabetical order.
