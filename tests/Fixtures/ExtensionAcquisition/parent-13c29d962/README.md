# Published extension-family 0.1.0-preview.4 schemas

These are byte-exact Git blobs from [finos/morphir](https://github.com/finos/morphir/tree/13c29d962c5907a1ce1da8395f060947b24772ee), commit `13c29d962c5907a1ce1da8395f060947b24772ee`.
`manifest.json` records the source repository, path, full commit and SHA-256 of every copied schema file. Tests verify these hashes offline from their output directory and validate both `0.1.0-preview.3` (`parent-65bbbc96`) and `0.1.0-preview.4` (`parent-13c29d962`) documents against their pinned schemas.

`0.1.0-preview.4` adds optional `capabilities.modelAccess` to the extension contract family while leaving `0.1.0-preview.3` frozen byte for byte.
