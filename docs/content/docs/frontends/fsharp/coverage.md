The F# frontend compiles a subset of F#. Before it lowers a document, admission checks the
syntax and refuses each construct outside the subset with an error diagnostic. All refusals
of a run are reported together, and the frontend writes no model. The
[overview](../) describes the supported subset.

This page is generated from the admission catalog of the frontend, so it lists every code
that admission can report. Each rule has a minimal example that gives only its own code. The
conformance corpus has one refusal case for each code. Codes are stable once released.

## Rules

### `fsharp.unsupported_mutable` {#fsharp-unsupported-mutable}

**Construct:** mutable binding or field

**Message:** Mutable bindings and fields are not supported; Morphir values are immutable.

**Suggestion:** Use a new let binding, or a record update, instead of changing a value.

**Example.** The diagnostic is at `mutable`.

`Example.fs`:

```fsharp
namespace Acme.Demo
module Example =
    let mutable total = 0
```

### `fsharp.unsupported_assignment` {#fsharp-unsupported-assignment}

**Construct:** assignment

**Message:** Assignment with '<-' is not supported; Morphir values are immutable.

**Suggestion:** Return a new value instead of changing an existing one.

**Example.** The diagnostic is at `builder.Length <- 0`.

`Example.fs`:

```fsharp
namespace Acme.Demo
module Example =
    let reset (builder: System.Text.StringBuilder) = builder.Length <- 0
```

### `fsharp.unsupported_loop` {#fsharp-unsupported-loop}

**Construct:** loop

**Message:** Loops ('for', 'while') are not supported; Morphir has no statements.

**Suggestion:** Use recursion or a List function such as List.map or List.fold.

**Example.** The diagnostic is at `for index in 1 .. 3 do ignore index`.

`Example.fs`:

```fsharp

```
