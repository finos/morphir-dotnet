The C# frontend compiles a subset of C# 15. After the C# compiler binds the documents without an error, an admission
analyzer refuses each construct outside the subset with an error diagnostic. All refusals of a run are reported
together, and the frontend writes no model. The [overview](../) describes the supported subset.

The same analyzer runs in the compiler, in the IDE and in `morphir compile`, so a refusal has one code, one message
and one range everywhere. A rule cannot be turned off: `#pragma warning disable`, `.editorconfig` and `NoWarn`
do not hide it, and a `SuppressMessage` attribute that names a rule is refused with `MORPHIR1008`. A construct
that a rule refuses cannot become a model, so change the construct. The absolute IRI of a rule is the help link
of its diagnostic. Codes are stable once released.

## `csharp.unsupported_loop`

- Roslyn id: `MORPHIR1001`
- Message: A '…' loop is not in the Morphir subset
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_loop`

Example:

```csharp
static class M
{
    static int F(int[] xs)
    {
        foreach (var x in xs) { }
        return 0;
    }
}
```

## `csharp.unsupported_mutation`

- Roslyn id: `MORPHIR1002`
- Message: A change of '…' is not in the Morphir subset
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_mutation`

Example:

```csharp
static class M
{
    static int F(int a)
    {
        a = 1;
        return a;
    }
}
```

## `csharp.unsupported_dynamic`

- Roslyn id: `MORPHIR1003`
- Message: 'dynamic' is not in the Morphir subset
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_dynamic`

Example:

```csharp
static class M
{
    static int F(dynamic d) => 1;

```

## `csharp.unsupported_mutable_property`

- Roslyn id: `MORPHIR1004`
- Message: Property '…' has a 'set' accessor
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_mutable_property`

Example:

```csharp
sealed record R
{
    public int X { get; set; }
}
```

## `csharp.unsupported_outside_reference`

- Roslyn id: `MORPHIR1005`
- Message: '…' comes from the assembly '…', which is outside the fixed reference set
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_outside_reference`

The analyzer reports a symbol from an assembly that the fixed reference set does not have. `morphir compile`
cannot bind such a symbol, so the C# compiler reports it first as `csharp.compiler`.

## `csharp.unsupported_type_kind`

- Roslyn id: `MORPHIR1006`
- Message: The … '…' is not in the Morphir subset. Use a record, a closed record, a union, an enum or a static class.
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_type_kind`

Example:

```csharp

```

## `csharp.unsupported_suppression`

- Roslyn id: `MORPHIR1008`
- Message: The attribute suppresses the Morphir rule '…'. A construct that a Morphir rule refuses cannot become a model; change the construct.
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_suppression`

Example:

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Morphir", "MORPHIR1001")]
static class M
{
    public static int F() => 1;
}
```

## `csharp.unsupported_non_partial_equality`

- Roslyn id: `MORPHIR1009`
- Message: The type '…' has IEEE equality from a MorphirEquality attribute and is not partial. Add 'partial' to the type, because the equality members are added to it.
- IRI: `https://morphir.finos.org/rules/csharp/unsupported_non_partial_equality`

Example:

```csharp
[Morphir.MorphirEquality(Morphir.FloatEquality.Ieee)]
public sealed record Quote(double Value);
```
