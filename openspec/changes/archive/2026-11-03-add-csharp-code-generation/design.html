Context

The F# backend already consumes VersionedModel and returns in-memory artifacts. Models and Pipeline target only net10.0. The generator must support both classic and v4 IR without JSON bridges. A supported output language version does not prove that an IDE compiler host can load the generator's dependency closure.

Goals and non-goals

Deliver types and executable logic through a host-independent C# library with explicit version profiles and located refusals. Exclude CLI registration, full Roslyn integration, source rewriting, arbitrary dependency implementation, open records, local recursive groups, native/external bodies and document literals.

Decisions

LAND-1. Squash-aware landing and cleanup

Prefer squash merging for initiative and archival PRs unless PR instructions or repository settings select another method. Record the actual method, the distinct final submitted head SHA and the hosting service's recorded landed SHA. Verify that the exact PR is merged into main and its landed commit is reachable from refreshed main. Original worker commits need not remain ancestors of main after a squash. Successors use main with the landed SHA. Before cleanup, verify a clean owned worktree and HEAD matching its last submitted PR head with no extra local commits; git branch --merged is not landing proof for a squash.

CSGEN-1. Keep the typed generation core independent of hosts

Add Morphir.CodeGeneration.CSharp with a VersionedModel entry point, immutable validated options, caller cancellation, and an immutable result containing relative generated sources, diagnostics and declared runtime requirements. Source records carry text and relative paths; host absolute paths belong in diagnostics, not source bytes. Reference Models directly, not Tooling or Ion. The CLI later adapts sources to VFileTree. Do not create a second public semantic IR or move all generation contracts into a new framework.

CSGEN-2. Freeze a deliberately small language profile table

Expose C# 14 and C# 15 as numeric language versions, default 14. Pin .NET 10 and .NET 11 RC compiler builds in test metadata; RC is toolchain status, not a third language version. Validate runtime requirements independently. Initially keep one immutable record/case representation valid under both profiles. New syntax is optional where it preserves the public contract; do not select native unions merely because version 15 permits them. Adding another version should require a small profile entry, mapping changes only when needed, and compiler evidence.

CSGEN-3. Lower types and expressions with explicit scope

Produce one stable .g.cs source per Morphir module, with package-derived namespaces, a static module class for values/functions, and stable named record/case types. Preserve alias transparency rather than inventing nominal wrappers for all aliases. SDK collections use the C# SDK's immutable value types. Fully applied functions use static methods; function values/partial application use typed nested Func values and lowering adapters. Allocate names in a shared per-generation map, preserve lexical scope and branch order, escape C# keywords and refuse unresolvable public/path collisions. Include top-level self recursion; refuse local recursive groups in this bounded slice.

CSGEN-4. Prefer direct deterministic text emission

Use an indented writer and explicit literal escaping. Keep separate classic and v4 typed admission/lowering functions with shared target naming/emission utilities where useful. Reuse existing type/scope validators only where dependencies and semantics fit; no hidden v4-to-classic conversion. Roslyn is a test/host dependency, not the production emitter's representation. Validate whole-model admissibility and return no successful partial sources on failure.

CSGEN-5. Establish modern compiler-host evidence early

Before freezing packaging, create a minimal test-only incremental generator/driver smoke that supplies an in-memory typed model, calls the proposed core and adds returned source. Prove it under a .NET 10 compiler host with the real dependency closure, with cancellation and no CLI process or ambient file reads. Record a host matrix and package-loading evidence. Broad netstandard2.0/legacy IDE-host support remains unclaimed. Do not blanket-retarget Models, Pipeline or codecs to pass the smoke; if a wider host contract becomes required, coordinate a separate compatibility change. The later real source generator will use AdditionalFiles, parse options, equatable inputs and AddSource.

CSGEN-6. Test behavior across dimensions instead of creating parallel suites

Reuse daily-rate, car-rental and relevant ecosystem inputs where their constructs are in the admitted slice. One behavior corpus varies classic/v4, stable/RC, supported representations at host boundaries and culture. Compile and execute C# against the actual SDK package and compare expected business results and conformance observations. Include negative cases for unsupported nodes, unresolved SDK references, representation loss, collision and cancellation. Snapshots help review source but do not replace execution.

Thread ownership and dependency gates

Start implementation only after add-immutable-csharp-sdk has a verified PR merged into main. Start the worker checkout from main containing those merge commits, not an unmerged sibling branch.

Use the exact worker brief and coordination rules. Runtime and generation signatures come from the merged predecessor. Shared solution, package and PRD-index edits are integrated serially. The delivery lead owns only this change and its listed implementation areas. The auxiliary policy permits up to three auxiliaries per lead, sharing an initial global budget of three across at most two initiative leads. Start with one auxiliary and check CPU/memory headroom before expanding; only an explicit resource assessment and root-coordinator decision can increase the global budget. All agents use Codex gpt-6.1-sol with reasoningEffort high through T3 delegate_task, with capability discovery before each thread's first delegation and no recursive fan-out. Coordinate the one delivery-wide expensive-command slot, bound internal parallelism, and back off under resource pressure. Use disjoint writing ownership or orchestrator-created isolated worktrees with serial integration. The lead integrates results and required checks into one initiative PR; the root coordinator retains watching, landing, archive follow-up and cleanup, including auxiliary worktrees/helpers. Cancel unneeded tasks with task_cancel and follow event-driven completion without polling.

Completion requires a PR merged into main, verification of the merge commit, and removal of this initiative's clean worker worktree. An open PR or checked task list is not completion. Preserve uncommitted or unrelated work; do not remove the coordinator's checkout.

Verification

Use the scenarios in morphir-csharp-transpilation and the per-group checks in tasks.md. Follow red/green/refactor for production behavior. Test actual packaged/runtime/generated consumers where applicable; record exact toolchain versions and commands. Before contribution, run the repository-required full suite, coverage and formatting checks in addition to focused tests. No AI coauthor trailers.

Land only after the PR's required checks and reviews pass. Link created or pushed PRs through the orchestrator. If checks or reviews are pending, the root coordinator uses the PR-watch mechanism and resumes from its event; delegated children never watch PRs. Final evidence records the PR URL, head and merge SHAs, checks/reviews, confirmed main inclusion and workspace cleanup.

A broad compiler-host promise forces repository-wide retargetingClaim only tested modern hosts now and publish the unsupported-host matrix.
Version-specific emission grows two backendsShare lowering and public representation; keep profile differences explicit and narrow.

Migration plan

Add the library and its consumer tests without CLI registration or changes to existing F# APIs. Consume the exact integrated C# SDK contract. Rollback removes the unused backend library. CLI integration remains a separate dependent change; source-generator delivery remains deferred.
